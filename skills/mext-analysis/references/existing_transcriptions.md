# すでに書き起こしがある場合

`X.matcha` がすでにある場合（前に matcha分析をした、または人が書いた）は、まず `python3 -m mext changed X.check.mext` で、書き起こしの時点から `X.matcha` と `X.matcha.md` が変わったかを確かめる（ハッシュ値で比べる）。

| `X.matcha` | `X.matcha.md` | 読み取れること | すること |
|---|---|---|---|
| 変わっていない | 変わっていない | 書き起こしのまま | matcha分析を省き、メモを出発点にする |
| **変わった** | 変わっていない | 人が書き起こしを直した | 利用者に確かめたうえで、**原文を全部読み直し**、今の `X.matcha` を正として新しいメモを作る（古いメモは `X.matcha.v1.md` などとして残す）。そのうえで `.mext` を新しく作る |
| 変わっていない | **変わった** | 人がメモを直した | メモを `X.matcha` と原文に照らして確かめる。食い違いがあれば、メモの作り直しを確かめ、提案する |
| **変わった** | **変わった** | 人が両方を直した | 原文を全部読み直し、二つを正として扱う。食い違いがあれば、確かめ、提案する |

- 人が直したものは人の判断である。**上書きしない**。同意できない点は、`X.matcha` を戻さずに、レポートと試算（`X.alt-*.mext`）で示す。
- 利用者に確かめられない場合（非対話の実行など）は、新しいメモを `X.matcha.proposed.md` として別に作り、そのことをレポートの冒頭に書く。
- `X.check.mext` がない、または `source:` の記録がない場合は、変更を判定できない。人が直した可能性があるものとして、原文を全部読み直す。
- メモがなく `X.matcha` だけがある場合は、原文を全部読んでメモから作る（原文もなければ matcha-default-extensions の仕事である）。
