# 小論: AI に判断させるより、AI に書かせたコードに判断させよ

（mext のテスト用に作った小論である。）

大規模言語モデル（AI）は、同じ質問に対しても、ときに違う答えを返す。業務の判断に AI を使うなら、この揺れは問題になる。そこで私は、判断を AI に直接させるのではなく、判断の手続きを AI に決定論的なコードとして書かせ、そのコードに判断させるべきだと考える。

理由は三つある。一つ目に、コードは同じ入力に同じ出力を返す。判断の揺れがなくなる。二つ目に、コードは人が読める。判断がなぜそうなったかを、後から検証できる（これを注意労働と呼んでもよい）。三つ目に、コードの誤りは、一度直せば二度と起きない。AI の判断の誤りは、次にまた起きるかもしれない。

ただし、すべての判断をコードにできるわけではない。文章の意味を読み取る、事実を評価するといった判断は、規則として書き下せない。そうした判断は AI に任せるしかない。その場合でも、AI の判断を理由とともに記録し、コードの部分と分けておけばよい。

したがって、AI を使うシステムでは、規則として書き下せる判断はすべて AI に書かせたコードで行い、書き下せない判断だけを AI に直接させるべきである。
