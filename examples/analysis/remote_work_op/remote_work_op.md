# 論説: リモートワークを「原則」にせよ

（mext のテスト用に作った架空の論説である。数字は例示のためのもので、実在の調査ではない。）

コロナ禍が明けて、出社を原則に戻す会社が増えている。しかし私は、事務職については、リモートワークを原則とし、出社を例外とすべきだと考える。

第一に、生産性である。ある民間の調査では、リモートワークを導入した会社の 6 割が「生産性は下がらなかった」と答えている。生産性が下がらないのなら、通勤という負担を社員に課し続ける理由はない。

第二に、人材の確保である。子育てや介護を担う人、地方に住む人は、毎日の出社が条件なら働けない。リモートワークを原則にすれば、そうした人たちを採用できる。人手不足の時代に、これを捨てるのはもったいない。

第三に、費用である。オフィスの面積を減らせば、賃料と光熱費を大きく削れる。

もちろん、出社に意味がある場面もある。新人の教育や、顔を合わせての議論が欠かせない企画の初期段階などである。そうした場面では出社を求めればよい。だが、それは例外として、理由を示して求めるべきものであって、出社そのものを原則にする理由にはならない。

「対面でなければ、社員の一体感が失われる」という反論もよく聞く。しかし一体感は、毎日同じ部屋にいることからではなく、目標を共有することから生まれる。オンラインでも目標は共有できる。

以上から、事務職についてはリモートワークを原則とし、出社は理由を示した例外とすべきである。
