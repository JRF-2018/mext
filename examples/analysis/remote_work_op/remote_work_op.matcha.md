## 1. 文書の論証の要約

- **主な結論**（第7段落）: 事務職については、リモートワークを原則とし、出社は理由を示した例外とすべきである。
- **支える筋**: 三つの根拠 —— (1) 生産性は下がらないので通勤の負担を課す理由はない（第2段落）、(2) 出社を条件にすると働けない人を採用できる（第3段落）、(3) オフィス費用を削れる（第4段落）。
- **反論への応答**: (a) 出社に意味がある場面はあるが、それは例外として理由を示して求めればよく、出社を原則にする理由にはならない（第5段落）。(b)「対面でなければ一体感が失われる」という反論には、一体感は目標の共有から生まれ、オンラインでも目標は共有できる、と答える（第6段落）。
- **書き起こした範囲**: 文書は短く（約 650 字）、主な結論は一つなので、反論への応答も含めて全部を書き起こした。

## 3. 書き起こしの判断

- **評価（@）として表に出したもの**: 5 つ。
  - 6割の回答 → 生産性は下がらない（L8）
  - 毎日の出社が条件なら働けない → リモート原則なら採用できる（L14）
  - 面積を減らせば削れる → リモート原則で削れる（L22）
  - 場面の列挙 → 例外にとどまる（L43）
  - 一体感の由来とオンラインでの共有 → 一体感は失われない（L50）
  
  いずれも原文が「から」「なら」で飛び越えている判断である。
- **三つの根拠の結び方**: 第7段落の「以上から」は三つをまとめた結論なので、AND（すべてが必要）として読んだ。各根拠が単独で足りる（OR）とも読めるので、OR の版を `remote_work_op.alt-or.matcha` で試算する。
- **反論の扱い**: 二つの反論は、どちらも要件が満たされないとして退けられている（原文は反論の前提そのものを否定する）。そのため、`:: 優先` ではなく `!` の主張にし、結論には不成立からの帰結を書いた（writing_matcha §2.2・§2.4）。
  - そのため、反論の主張は `!>` で主な結論と結ばれていない。反論が成り立った場合の扱いは、試算（`[extra]`）で示す。
- **例外としての出社**（第5段落前半）は、文書が積極的に認めた主張なので、成立の主張として別に書いた。対象は「新人の教育や企画の初期段階」。
